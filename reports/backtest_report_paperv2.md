## 二、收益集中度：诊断、解释与治理

**诊断**（对 v1）：LGB_ew10 超额收益最大单月 2024-09 达 +25.2%，top5 月超额对数贡献 >100%。

**解释**：
1. A 股绝对收益本身事件驱动——沪深300 自身 top5 月占对数收益 424%（2019-01/2020-06/2022-10/2024-09/2025-07 政策脉冲月），任何 long-only 组合无法避免，这部分是 beta 补偿；
2. 但超额收益也集中，说明 v1 的"alpha"有相当部分是**未控制的因子押注**：分类标签 P(前向12月收益>0) 天然偏向高 β 小票（12 个月赚钱概率与 β 正相关），Top10 等权无约束进一步放大。

**治理**（标签维持论文口径不动，治在组合层）：
1. 特征扩展（见下）——信号来源多元化；
2. MW 风格盒约束加入 **beta250**（250 日滚动 β 截面 z，±0.35）。

**效果**：LGBv2_mw 月 β 0.75，top5 月绝对贡献 **131% → 94.6%**（<100% = 不再依赖个别爆发月回补）；超额最大单月 +25.2% → +22.9%。

## 三、11 因子详细定义

| 因子 | 公式 | 类别 | 来源 |
|---|---|---|---|
| or_yoy | `rev_ttm / rev_ttm[-4季] − 1` | 成长 | 利润表单季化→TTM（PIT首披） |
| np_yoy | `np_ttm / np_ttm[-4季] − 1`（归母净利） | 成长 | 同上 |
| roa | `np_ttm / avg(total_assets) × 100` | 质量 | 利润表+资产负债表 |
| ps | `total_mv / rev_ttm` | 估值 | 估值表+利润表 |
| pcf | `total_mv / ocf_ttm`（ocf≤0 置空） | 估值 | 估值表+现金流量表 |
| ep | `1 / pe_ttm`（亏损置空） | 价值 | 估值表（Tushare） |
| revs20 | `−(hfq_close / hfq_close[-20日] − 1)` | 反转 | 日线（后复权） |
| std60 | `std(daily_ret, 60) × √244`（有效观测≥40） | 波动 | 日线 |
| turn20 | `mean(turnover_rate, 20日)` | 流动性 | Tushare换手率 |
| accrual | `(np_ttm − ocf_ttm) / total_assets × 100` | 质量（应计） | 三表 |
| gpm | `gp_ttm / rev_ttm × 100` | 质量（毛利率） | 利润表 |

风格约束变量（不进特征）：`size=−ln(流通市值)`、`beta250=cov(r_i,r_m,250d)/var(r_m,250d)`。

## 四、完整算法数学形式

### 4.1 预处理（每个信号月截面 t 独立执行）
对每个因子 k：缩尾 `w = clip(x, q_{0.01}, q_{0.99})`，再截面标准化 `z = (w − μ)/σ`。

### 4.2 标签（PIT 铁律）
`y_{i,j} = 1{ P^{hfq}_{i,open}(T_{j+12}+1日) / P^{hfq}_{i,open}(T_j+1日) > 1 }`
训练月 j 须满足 j+12 < i（标签已完整实现），即训练窗 `[i−25, i−13]`，**防前视**。

### 4.3 LightGBM 分类器
逐叶贪心生长，最大化分裂增益：

`Gain = [GL²/(HL+λ) + GR²/(HR+λ) − (GL+GR)²/(HL+HR+λ)] − γ`

二分类损失（负对数似然）：`L = −Σ[y ln p + (1−y) ln(1−p)]`，输出 `p = P(y=1|z)`。原生支持 NaN（缺失即分裂方向）。

### 4.4 贝叶斯调参（scikit-optimize gp_minimize，200 calls）
- 搜索空间：`max_depth∈[1,20]`, `n_estimators∈[1,400]`, `subsample∈[0.4,1]`, `min_split_gain∈[0,1]`, `reg_alpha,reg_lambda∈[0.005,30]`
- 目标（最大化）：`(Precision+Recall+Accuracy+AUC)/4`，5 折 CV 内估计
- 高斯过程代理 `f(x) ~ GP(m(x), k(x,x'))` + 期望改进采集 `EI(x) = E[max(f(x)−f*, 0)]`
- 本次最优：`max_depth=16, n_estimators=400, subsample=0.4, min_split_gain=0, reg=0.005`（低 subsample = 强正则；贝叶斯仅 +0.003 AUC）

### 4.5 约束 Markowitz 组合（月调，Top20）
`max_w  w'μ̃ / √(w'Σw)`  s.t. `Σw=1, 0≤w_i≤0.12`；
行业哑变量盒约束 `|Σ_{i∈j}w_i − u_j| ≤ 0.10 ∀j`；
风格暴露盒约束 `|w'z_k| ≤ 0.35, k ∈ {size, ep, revs20, std60, turn20, beta250}`。
其中 `μ̃ = 0.7·p + 0.3·mean(p)`（贝叶斯收缩），`Σ` = Ledoit-Wolf 收缩协方差（过去 12 个月日收益）。
调仓阈值：`adv = w_new'p − w_old'p < 0.5%` 则维持原持仓。换手率成本 `cost = Σ|Δw| × 1bp`。

### 4.6 统计检验
- **FM 回归**：`r_{i,t+1} = α_t + Σ_k β_{k,t}·z_{k,i,t} + ε`，逐月 OLS 取系数时间序列均值与 Newey-West t（滞后 6 期）。
- **GRS**：`GRS = (T/N)·[α̂'(Σ̂_e)^{-1}α̂] / (1 + μ̂_F'Σ̂_F^{-1}μ̂_F) ~ F(N, T−N−K)`。

### 4.7 FM 结果（v2 11因子）
| 因子 | NW_t | | 因子 | NW_t |
|---|---|---|---|---|
| turn20 | **-4.21** | | np_yoy | 2.27 |
| pcf | **-2.77** | | roa | 2.09 |
| ps | -2.23 | | revs20 | 1.40 |
| or_yoy | **+2.42** | | ep / std60 / accrual / gpm / alpha | 不显著 |

GRS：2.29，p = 0.082（边际）。特征重要性：roa≈gpm>np_yoy>or_yoy>accrual（质量/成长主导，量价 revs20 最低 0.044）。

## 五、日度因子补充与提升建议

### 5.1 可补充的日度/高频因子（本地 1 分钟数据可直接计算）

| 因子 | 构造 | 预期作用 |
|---|---|---|
| 隔夜收益因子 | `r_overnight = open_t/pre_close_t − 1`，20 日累计 | A 股隔夜与日内收益分裂明显，隔夜动量/反转 |
| 尾盘成交占比 | `mean(volume_{14:30-15:00} / volume_day, 20日)` | 机构尾盘行为，低占比利好（聪明钱分散） |
| 高频偏度 | 分钟收益偏度，20 日 | 负偏度溢价（彩票效应） |
| 下行波动占比 | `std(r⁻)/std(r), 20日`（分钟级） | 与 std60 低相关，纯下行风险定价 |
| 理想反转（W切割） | 按成交额加权切割日内 vs 隔夜动量 | 比 revs20 更强的反转提纯 |
| 换手率稳定性 | `std(turnover,20)/mean(turnover,20)` | 与 turn20 正交（16因子体系已有定义） |
| Amihud 非流动性 | `mean(|ret|/amount, 20日)` | 流动性溢价（16因子体系已定义） |
| 大单净流入 | 分钟级主动买卖盘（需逐笔，可用 1 分钟量近似） | 主力资金行为 |
| 波动率的波动 | `std(std60, 12月)` 或分钟已实现波动率的波动 | 不确定性溢价 |
| 最大单日收益 MAX | `max(daily_ret, 20日)` | 彩票效应/恐惧因子 |

### 5.2 建模层提升
1. **LambdaRank/回归标签替代分类**：把 0/1 标签换成前向 12 月收益的截面 rank（或相对基准的超额 rank），保序统计更高效，AUC 口径损失的信息可回收；
2. **样本时间加权**：指数衰减加权近期样本（半衰期 6-12 月），适配 A 股风格漂移；
3. **特征中性化后再入模**：当前特征未中性化，size 混杂（ps/pcf 负溢价即小市值代理）——先对 size+行业取残差再进 LGB，可让模型专注特质信息；
4. **滚动重训频率**：当前每年重训（论文形式），可试季度重训（标签滞后约束不变，无泄漏）；
5. **集成**：LGB + RF 堆叠（RF 在首窗 AUC 最高 0.755），或分桶模型（大/小市值分开训练）。
