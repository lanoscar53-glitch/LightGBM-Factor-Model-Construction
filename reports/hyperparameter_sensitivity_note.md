# 附加文档：LightGBM 超参数校准窗口敏感性分析

> 数据基础：`monthly_returns_paperv2.csv`（10年版全窗口月收益）、`monthly_returns_paperv2_2020.csv`（2020窗口重跑版月收益）

## 1. 背景与问题

本项目在同一套策略体系（LightGBM-Bayes 11因子选股，Top20 Markowitz + Top10 等权，月/季调仓，单边万一）下做了两次回测：

| 版本 | 信号窗口 | 贝叶斯校准样本 | MW组合表现 | EW10组合表现 |
|---|---|---|---|---|
| 10年版（v2） | 2016-10 ~ 2026-09 | 训练窗止于 ~2016-09 | 全窗口夏普 0.50 / 年化 9.3% | 全窗口夏普 0.37 / 年化 6.5% |
| 10年版截取 2020 起 | 2020-01 ~ 2026-09（同序列截取） | 同上 | **夏普 0.70 / 年化 15.3%** | **夏普 0.71 / 年化 17.4%** |
| 2020窗口重跑版 | 2020-01 ~ 2026-09 | 训练窗止于 ~2018-12 | 夏普 0.30 / 年化 4.8% | 夏普 0.44 / 年化 9.0% |

**核心发现**：截取版与重跑版在完全相同的 81 个月上，MW 组合月均收益差 **-0.81%（t=-1.82，10% 水平显著）**，EW10 差 -0.66%/月（t=-1.01）。两个版本的数据、因子、标签、组合构建规则完全一致，唯一差别是**贝叶斯超参数优化器所看到的首窗训练集不同**（校准窗口 2005–2016 vs 2008–2018），导致 `gp_minimize` 收敛到不同的超参数组合，进而使 2020 年后每一次年度重训的模型都不同，持仓路径显著分化（2021 年分化最明显：10年版 MW 净值冲高 1.8，重跑版仅 1.35 并于 2022 年跌至 0.78）。

## 2. 机制分析：为什么校准窗口会改变结果

### 2.1 两次运行的唯一代码路径差异

```
SIG_MIN: "2016-10-01"  →  i0 = 2016-10 的首个信号月
SIG_MIN: "2020-01-01"  →  i0 = 2020-01 的首个信号月

collect_train(i0) 取 [i0-24, i0-13) 共12个月的滞后训练窗(标签滞后13个月, 防前视)
  → 10年版校准样本: ~2005-09 ~ 2016-09
  → 重跑版校准样本: ~2008-01 ~ 2018-12

gp_minimize(bayes_obj, n_calls=200, x0=原文最优值, random_state=42)
  → 目标函数 = 5折CV 的 (Precision+Recall+Accuracy+AUC)/4
  → 两次校准样本不同 → 目标函数曲面不同 → 收敛点不同
  → 此后每次年度重训的 LGBMClassifier(**BEST) 超参不同
```

关键点：**年度重训的训练月份集合两次运行完全相同**（都由信号月 i 唯一决定，滞后 13 个月），因此差异几乎全部来自 `BEST` 超参数，而非数据或实现。这排除了"数据泄漏/口径错误"的解释——这是纯粹的**超参数估计敏感性**。

### 2.2 超参数→模型→组合的分化放大链

1. **校准目标与真实目标的错位**：贝叶斯优化以样本内 CV 分类指标（P/R/Acc/AUC 均值）为目标，而回测目标是样本外月度风险调整后收益。CV 分类指标对超参数的偏好与样本外夏普的偏好并不一致，且这种不一致程度随市场 regime 变化（2005-2016 覆盖股权分置后牛市与 2015 股灾；2008-2018 增加 2017 蓝筹年与 2018 熊市尾部）。
2. **小差异被 Markowitz 放大**：MW 组合对预期收益估计敏感（`pick_markowitz_constrained` 以预测概率为 μ），预测概率的微小排名变化即可改变入选的 20 只股票及其权重；盒约束（行业10%/风格35%/单票12%/beta钳制）限制了暴露但**没有正则化 μ 的估计误差**。
3. **路径依赖**：年度重训 + 月度调仓阈值（0.5%）意味着早期的持仓分化会自我延续——不同的 2020-2021 持仓经历不同的盈亏，触发不同的调仓，误差沿路径累积。

## 3. 量化证据汇总

| 证据 | 数值 | 解读 |
|---|---|---|
| MW 月均差异 | -0.81%，t=-1.82 | 10% 水平显著，差异非纯噪声 |
| EW10 月均差异 | -0.66%，t=-1.01 | 不显著——等权组合对超参敏感度低于 Markowitz |
| 10年版全窗口 MW 夏普 0.50 vs 截取2020后 0.70 | 窗口选择效应 | 2016-2019 段（熔断/熊市）拉低了全窗口指标；**截取子窗口会系统性美化指标** |
| 两版 GRS p 值 | 0.082 / 0.083 | 因子模型均无法完全解释组合收益（含超参数带来的隐性"第六因子"） |

> 注意区分两种效应：①**校准窗口敏感性**（本次对比的核心）；②**窗口截取偏误**（同一组合在不同子窗口表现不同）。`wealth_paperv2_sliced2020.png` 展示的是②的呈现，而两版对比揭示的是①。做策略评估时两者必须分开报告。

## 4. 结论与建议

### 4.1 对当前结果的解读
- 单点贝叶斯校准的超参数**不可视为稳定真值**：本次 t=-1.82 表明校准窗口移动 3 年即可产生统计可辨的表现差异。
- EW10（等权）对超参的鲁棒性显著好于 MW（Markowitz）——预期收益加权对估计误差更敏感，与组合理论一致。
- 因此 GitHub 发布时，应把"10年版"与"2020重跑版"并列为**敏感性测试的证据**，而不是把任一版当作点估计。

### 4.2 工程改进建议（按性价比排序）
1. **固定保守超参做基线**：用文献常用值（max_depth=6, n_estimators=200, subsample=0.8, reg_lambda=1.0）跑一遍作为 anchor。若贝叶斯版无法稳定跑赢 anchor，则贝叶斯调参在本任务的边际价值存疑。
2. **滚动校准（walk-forward hyperparameter tuning）**：每年重训时同步用最近 3 年样本重跑小规模贝叶斯（n_calls=50），而非全历史单点校准一次——让超参与市场 regime 同步漂移。
3. **超参集成**：取贝叶斯后验的 Top-3 超参组合分别建模，对预测概率取平均（近似 BMA），平滑单点超参的估计误差——成本低（3倍训练），对 MW 组合的 μ 噪声特别有效。
4. **降低 MW 的 μ 敏感度**：盒约束中增加预测置信度过滤（仅取预测概率 top 分位内做 MW），或对 μ 做跨期收缩（μ̂_shrunk = 0.5·μ̂_LGBM + 0.5·μ̂_12月动量反转）。
5. **报告规范**：任何基于贝叶斯调参的回测，应至少附两个不同校准窗口的重跑结果并报告差异 t 值；单点调参+单窗口回测的结果不应进入资金决策。

### 4.3 局限性
- 两次运行各只有一条路径，差异检验功效有限（t=-1.82 仅 10% 水平）；更严格的做法是固定校准窗口、对训练数据做 bootstrap 重采样，估计超参分布的样本外表现方差。
- 本分析只覆盖 LightGBM；XGBoost/RF 的校准敏感性未单独检验（首窗对比中 RF 分类指标最优，可作交叉验证切入点）。
